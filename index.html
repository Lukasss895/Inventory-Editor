Valve inventory.txt Format Specs

CS:GO & CS2 inventory state files use Valve's standard KeyValues text format. The structure utilizes hierarchical block syntax: 

"items"
{
  "1"
  {
    "def_index" "7"
    "paint_index" "180"
    "rarity" "4"
    "wear" "0.0521"
    "stattrak" "1"
    "custom_name" "My AK"
  }
}
